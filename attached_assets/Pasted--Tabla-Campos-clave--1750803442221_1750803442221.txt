| Tabla                    | Campos clave                                                                                       | Comentarios críticos                                    |
| ------------------------ | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| `tenants`                | id, nombre\_legal, rfc, timbre\_sat\_id                                                            | Multi-escuela SaaS, cada tenant emite sus propios CFDI. |
| `campuses`               | id, tenant\_id, nombre, clave\_sep                                                                 | División física.                                        |
| `users`                  | id, campus\_id, email, hash\_pass, rol, tfa\_secret                                                | Roles: super\_admin, admin, cajero, contador, tutor.    |
| `students`               | id, campus\_id, curp, nombre, grado, grupo, status                                                 | Status: activo, suspendido, baja, egresado.             |
| `guardians`              | id, email, telefono, nombre, rfc\_fiscal                                                           | Puede no ser usuario (solo receptor de CFDI).           |
| `student_guardian`       | student\_id, guardian\_id, porcentaje\_responsabilidad                                             | Soporta pagos divididos (50/50, etc.).                  |
| `concepts`               | id, campus\_id, nombre, tipo (colegiatura, inscripción, extra), periodicidad, iva                  | Parametriza N conceptos.                                |
| `charges`                | id, student\_id, concept\_id, ciclo\_id, fecha\_venc, monto\_base, beca\_pct, recargo\_pct, estado | Estados: pendiente, pagado, parcial, cancelado.         |
| `payments`               | id, charge\_id, metodo, referencia\_pasarela, monto, fecha, estado                                 | Estados: exitoso, fallido, reversado.                   |
| `payment_methods`        | id, guardian\_id, tipo (card, spei, paypal), token\_pasarela, last4, exp                           | Tokenización PCI.                                       |
| `invoices`               | id, payment\_id, uuid\_sat, xml\_url, pdf\_url, estado                                             | CFDI 4.0.                                               |
| `discounts`              | id, campus\_id, nombre, regla\_sql, monto\_pct                                                     | Regla condicional (e.g. pronto pago).                   |
| `scholarships`           | id, student\_id, pct, vigencia\_inicio, vigencia\_fin, motivo                                      | Becas individuales.                                     |
| `notifications`          | id, user\_id, canal (email, sms, whatsapp), payload\_json, enviado\_en                             | Guardar bitácora.                                       |
| `reconciliation_batches` | id, campus\_id, banco, fecha\_inicial, fecha\_final, archivo\_csv, estatus                         | Conciliación.                                           |
